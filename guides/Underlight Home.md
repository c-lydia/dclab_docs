## Start here

| When you want to… | Do this |
| --- | --- |
| Capture something quickly | **Ctrl+N** → it lands in `00 Inbox` |
| Plan today | **Ctrl+Alt+D** → daily plan, work log, and reflection |
| Start a structured note | Name a new note → **Ctrl+Alt+T** → choose a template |
| Find a note | **Ctrl+O** → type its name |
| Search everything | **Ctrl+Shift+F** |
| Learn the setup | [Underlight Guide](Underlight%20Guide.md) |

## Workbench

**Build** · `projects` — robotics, ROS 2, embedded systems, software, experiments.

**Study** · `research` — papers, courses, sources, and questions to investigate.

**Understand** · `courses` — concepts and explanations written in your own words.

**Reflect** · `05 Journal` — personal notes and weekly reviews.

Templates: [Project](../templates/notes/Project.md) · [Experiment](../templates/notes/Experiment.md) · [Research](../templates/notes/Research.md) · [Concept](../templates/notes/Concept.md) · [Journal](../templates/notes/Journal.md) · [Weekly review](../templates/notes/Weekly%20Review.md)
