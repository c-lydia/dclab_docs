Course Description

This course is designed to provide a comprehensive introduction to control system. Students will learn the fundamentals of control system, including electronics, microcontroller, communication protocol, PID, manual control, and odometry. The course will primarily use STM32, C/C++, Python, OOP, and ROS 2. By the end of the course, students should be able to control basic robot with gamepad app and solve basic problems with the robot control system code and electronics.

Prerequisite: Mechanics, Circuit Analysis, Arduino and ESP 32 platform, Python, C/C++, OOP, ROS 2
